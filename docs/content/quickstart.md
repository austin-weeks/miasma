# Quickstart

Thanks for choosing Miasma - let's get you up and running!

## Choose an Execution Method

First, pick a way to run and deploy Miasma. This is a matter of preference and depends on how you choose to host your site.

- :lucide-file-code-corner: [Run Miasma as a standalone program](/running-locally){:target=blank}
- :fontawesome-brands-docker: [Use the Miasma Docker Image](/docker){:target=blank}
- :fontawesome-brands-rust: [Integrate into an existing Rust server](/library){:target=blank}

## Set up a Scraper Trap

Then, direct AI scrapers to your running instance of Miasma. Learn more in our [how to trap scrapers](/how-to-trap-scrapers){:target=blank} guide.

## Fine Tune Configuration

Finally, read through Miasma's [configuration settings](/settings){:target=blank} and pick the options that make sense for your site.

## Set up Tracking Metrics (Optional)

Miasma offers the ability to track scraper activity through its [metrics](/metrics){:target=blank} feature.

## Getting Help

Have questions or need support? Check out our [issues page](https://github.com/austin-weeks/miasma/issues){:target=blank}.
